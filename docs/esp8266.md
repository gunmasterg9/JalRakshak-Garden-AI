# JalRakshak Garden AI — LOLIN NodeMCU V3 ESP8266 Firmware & Calibration Guide

## Hardware Specifications & Pinout

The **LOLIN NodeMCU V3 (ESP8266EX)** operates alongside the ESP32 in JalRakshak Garden AI as a dedicated sensor node for localized microclimate and soil monitoring.

| Component | Sensor Pin | NodeMCU Pin | ESP8266 GPIO | Electrical Specification |
| :--- | :--- | :---: | :---: | :--- |
| **DHT11 Temp / Humidity** | DATA | **D2** | **GPIO4** | 3.3V logic; 10kΩ pull-up resistor to 3V3 rail |
| **DHT11 Power** | VCC / GND | **3V3 / GND** | — | Regulated 3.3V power |
| **Soil Moisture (LM393)** | AOUT (Analog) | **A0** | **ADC0** | 10-bit ADC (0–1023); onboard 220kΩ/100kΩ divider supports 0–3.3V |
| **Soil Sensor Power** | VCC / GND | **3V3 / GND** | — | 3.3V rail |
| **USB Serial (CH340)** | Micro-USB | **USB** | TXD0 / RXD0 | COM port, 115200 baud |
| **Pump Actuator** | Leads | — | — | **LOCKED (Safety Disabled)**: Actuation disabled pending external relay module |

## ADC Architecture & Calibration for 10-bit ADC

Unlike the 12-bit ADC on ESP32 (0–4095), the ESP8266 features a **10-bit Analog-to-Digital Converter** returning values from **0 to 1023**.

> [!IMPORTANT]
> The NodeMCU V3 board includes an integrated 220kΩ / 100kΩ resistor voltage divider directly on pin `A0`. This allows external analog signals up to **3.3V** to be safely measured. (Note: Bare ESP8266EX chip pins without a divider have a strict 1.0V maximum limit).

### 10-bit Calibration Defaults:
- **Dry Value (Air):** `800` (raw ADC in bone-dry air)
- **Wet Value (Water):** `350` (raw ADC submerged in water)

### Formula Used:
$$\text{Soil Moisture \%} = \text{constrain}\left(\frac{\text{DRY\_VALUE} - \text{Raw ADC}}{\text{DRY\_VALUE} - \text{WET\_VALUE}} \times 100\%, 0.0, 100.0\right)$$

## Build Targets & Flashing

### 1. PlatformIO (Recommended)
Project directory: `firmware/esp8266-garden-controller/`
```powershell
python -m platformio run -d firmware/esp8266-garden-controller --target upload --upload-port COM4
```

### 2. Arduino IDE
Open `firmware/esp8266-garden-controller/esp8266-garden-controller.ino`:
- **Board:** NodeMCU 1.0 (ESP-12E Module)
- **CPU Frequency:** 80 MHz
- **Flash Size:** 4MB (FS: 2MB OTA: ~1019KB)
- **Upload Speed:** 115200

## Telemetry Payload Schema

The ESP8266 dispatches non-blocking JSON telemetry every 15 seconds to `POST /api/iot/telemetry`:

```json
{
  "device_id": "esp8266-garden-01",
  "timestamp": "2026-10-10T02:56:00Z",
  "temperature_c": 28.5,
  "humidity_percent": 60.0,
  "soil_moisture_percent": 45.0,
  "raw_adc": 650,
  "water_level_percent": null,
  "pump_on": false,
  "is_simulated": false,
  "firmware_version": "1.2.0-esp8266",
  "wifi_rssi": -65,
  "ip_address": "192.168.1.150"
}
```

Sensors that are not physically connected report `null`, which the JalRakshak backend and frontend cleanly display as **"Not Connected"** without triggering false critical warnings.
